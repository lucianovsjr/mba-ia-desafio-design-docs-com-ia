# Debates

Artefatos de processo do fluxo de RFC, um diretório por documento em debate
(`RFC-001/`). Cada diretório guarda as análises independentes dos três
especialistas e a ata do debate, escritas pela skill `rfc-debate`.

Não são documentos de design e não entram no `docs/TRACKER.md`. Servem para
mostrar de onde saíram as questões em aberto da RFC e as decisões registradas
como ADR.
